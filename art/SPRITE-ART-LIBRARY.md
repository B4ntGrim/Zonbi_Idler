# Zed Idler art library

Open [index.html](index.html) to browse every image by category, search filenames, or select originals, game sprites, sheets, frames, and animated previews.

## Folders

| Folder | Contents |
| --- | --- |
| animals | Birds, riding mounts, mythical creatures |
| humans | Survivor loadouts, factions and NPCs, action poses |
| Vehicles | Bicycles, cars/vans/trucks, motorcycles, sportbikes, lightcycles |
| zombies | Existing game sprites |
| zombies/generated-originals | Full-resolution bestiary art by tier and original key poses |
| zombies/animations/grayscales | Animation sheets, individual frames, GIF previews |
| weapons/axes | Source axe artwork |
| weapons/items | Source item images, including weapons, equipment, food |
| weapons/sprites | Game-ready images and their mappings |
| weapons/concepts | Concept definitions and prompts |
| weapons/incoming | Incoming artwork instructions |
| reference/generated-sprite-sources | Generation prompts and source documentation |
| reference/catalog | Full searchable inventory in CSV and JSON |
| reference/imports | Import history and source-to-destination mappings |
| reference/organization-history | Earlier library guides and catalogs |

The catalog groups mixed item images under Food, Equipment, and Weapons without changing the file paths used by the game. Original artwork and game-sized versions remain separate. All existing image files and their contents were preserved during organization.

New sprite artwork belongs under the matching subject folder in E:\Zed_Idler\art. Game integration mappings should be updated explicitly when adding or changing assets.

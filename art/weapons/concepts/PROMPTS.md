# Weapon Forge — art prompts

Paste one prompt per image into the team's image tool. Save the result as
`art/weapons/concepts/<id>.png` (exact id), then run `python3 tools/weapon-forge/forge.py all`.

**House style (every prompt):** Retro 16-bit dark survival pixel art, desaturated earth and steel palette, crisp pixel grid, dark outlines, one weapon only, side view, whole weapon visible, centred, plain dark charcoal background, no text, no hands, no scenery.

# Zed Idler zombie art

Twelve individual zombie character illustrations generated with the built-in image generation tool.

- Format: PNG with an alpha channel and transparent background.
- Art: polished, gritty, stylized hand-painted enemy designs.
- Each image shows one static key pose. These are not animated sprite sheets.
- Original output sizes are preserved; dimensions vary between characters.
- Full generation prompts are in `prompts.md`.

# handoff/to-design

Files going **to Claude Design**: Code's technical reviews, acceptance reports, Design Handoffs and the current `CODE_STATE.md` snapshot.

How it works:
1. Code places everything for one handoff here, with a short message for Sam to paste.
2. Sam uploads this folder's contents to Claude Design in one go.
3. Once Claude Design has applied them, they are archived and this folder is cleared for the next handoff.

Code owns `CODE_STATE.md`; Claude Design owns the briefs, `CURRENT_BATCH.md`, `DESIGN_HANDOFF.md` and the index.

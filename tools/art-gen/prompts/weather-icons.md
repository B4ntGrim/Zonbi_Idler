# Weather icons — Clear, Rain, Fog, Heat Wave, Blizzard (WX-01 B8)

The current icons do not match the retro style. Five icons, one per weather. Generate each
separately so they can be iterated on; keep them a matched set.

Single image each, square, item-icon scale.

## Prompt
Retro pixel art weather icon in a matched set of five, chunky readable pixels, flat even lighting,
muted post-apocalyptic palette, 1px dark outline (#120d0a) around the silhouette, transparent
background, single symbol, centred, nothing cropped. Render ONE of the following, specified per run:

CLEAR — a pale sun disc with short straight rays, bleached bone-white and faded gold, a thin haze
of dust across it.
RAIN — a heavy slate-grey cloud with four straight diagonal rain streaks below it in cold blue.
FOG — three flat horizontal bands of pale grey mist, stacked and slightly offset, with a dim shape
half-swallowed behind them.
HEAT WAVE — a swollen orange-red sun low on a cracked horizon line, with three wavering heat-shimmer
lines rising from it.
BLIZZARD — a dark cloud driving snow sideways in hard diagonal streaks, with three angular
six-point snowflakes, in cold blue and white.

no text, no watermark, no border, no frame, no drop shadow, no gradient background, no
photo-realism, no multiple symbols, no cropping

## Notes for Sam
Run this five times, swapping in one weather line each time. Keeping the shared paragraph identical
is what makes them look like a set rather than five separate drawings.
